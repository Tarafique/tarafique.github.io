Project notes

Inspection firmware and device workflows

Firmware contributions to a commercial-vehicle inspection prototype built around ESP32-S3.

Project stageV1.1 engineering prototype assembled; field evaluation followed
RoleFirmware integration and testing within a team

Context

The device combines local inspection workflows with sensor information on an ESP32-S3 platform. The wider system uses a display, tire-related BLE sensor workflows, motion sensing, and local record handling.

Areas of contribution

  • Worked on the embedded display and device-input workflow.
  • Contributed to BLE tire-sensor behavior and sensor-related diagnostic work.
  • Investigated persistent configuration, local storage and device logging.
  • Supported inspection-result handling and firmware validation during prototype development.

System overview

BLE / TPMSSensor data
ESP32-S3Firmware
Device UIInspection records

Prototype stage

The team assembled a V1.1 engineering prototype for controlled field evaluation. Tire-sensor calibration and wider vehicle testing were subsequent steps. This is not presented as a fully validated commercial product.

Engineering considerations

An inspection device needs consistent user interaction, reliable sensor input and predictable storage behavior. Diagnostics and explicit record handling make faults easier to identify during testing.

Publication scope

This is a high-level public summary of a client-owned prototype. Proprietary source code, PCB designs, inspection data, and internal technical documents are intentionally excluded.
