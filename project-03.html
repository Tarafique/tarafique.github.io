Project notes

Sensor-based motor control

Experiments in sensing, command transport, PWM output and position feedback using ESP32 firmware.

Project stagePrototype testing ongoing
RoleFirmware integration, debugging and bench tests

Context

The demonstration links movement measured by a handheld board to a motorized rack, with communication and feedback stages between input and actuation.

Work included

  • Motion sensor bring-up and interpretation of accelerometer data.
  • Individual testing of PWM motor output and directional response.
  • Bluetooth audio-path and packet decoding investigation.
  • Experiments in proportional mapping and position-feedback control.

Simplified flow

IMUMotion input
FirmwareMapping / comms
MotorPWM output

Test results and limitations

Local motor and firmware tests demonstrated parts of the actuation path. Communication stability and magnetic-feedback repeatability remain under investigation, so accurate closed-loop positioning is not claimed.

Next technical check

Establish a repeatable position-to-sensor relationship before making further closed-loop tuning decisions. Isolated tests help distinguish sensing problems from PWM control and communications.

What the work involved

The investigation required separating sensor measurements, transport data, decoded commands and physical motor response to locate the source of inconsistent behavior.
