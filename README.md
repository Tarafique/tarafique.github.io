# Embedded engineering portfolio

Open `index.html` in a browser. No build step or external dependencies are required.

This version includes four detailed project pages and a quieter section summarizing additional engineering work. Technical areas separate project-based experience from ongoing project development. Client and product project names are intentionally omitted.

## Files
- `index.html` — main portfolio, broader project summaries, systems/tools and continuing work
- `project-01.html` to `project-04.html` — high-level case studies
- `styles.css` and `script.js` — styling and navigation
- `assets/talha-portrait.webp` — included local portrait

## Before publishing
- Supply your verified contact details and public repository links.
- Obtain permission before publishing client hardware photos, code, design files, logs or documents.
- Check stage and role descriptions against the latest project status.
- Revisit any *under development* descriptions as validation progresses.
